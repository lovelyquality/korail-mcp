# 🛒 조달·자재 정보 조회

KORAIL 자재 그룹·나라장터 품목·자재 속성 및 장비를 조회하는 MCP 서버 (도구 4개)

> 📌 이 폴더의 도구는 통합 서버 `korail-mcp` 에 포함되어 함께 제공됩니다(개별 등록 불필요). 설치는 [루트 README](../README.md) 참고. 본 서버는 **로컬 CSV 전용**이라 외부 API·프록시를 사용하지 않습니다.

| 도구 | 설명 |
|---|---|
| `search_material_group` | 자재 그룹 검색 |
| `search_g2b_item` | 나라장터(G2B) 품목 검색 |
| `search_material_attr` | 자재 속성 검색 |
| `search_material_equipment` | 자재 장비 검색 |
